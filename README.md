## 🚀 التثبيت والتشغيل

### المتطلبات المسبقة
- Node.js 18+
- MongoDB 6+
- npm أو yarn

### 1. تثبيت الواجهة الأمامية
```bash
cd /workspace
npm install
npm run dev
```

### 2. تثبيت الخلفية
```bash
cd /workspace/backend
npm install
npm run dev
```

### 3. إعداد متغيرات البيئة
انسخ ملف `.env.example` إلى `.env` وأضف مفاتيح API:
```
VITE_OPENAI_API_KEY=sk-your-key
VITE_GOOGLE_AI_KEY=your-google-key
VITE_ANTHROPIC_KEY=your-anthropic-key
MONGODB_URI=mongodb://localhost:27017/tabib-al-ajaeib
JWT_SECRET=your-secret-key
```
