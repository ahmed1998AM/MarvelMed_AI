## 🔌 API Endpoints

### المصادقة
- `POST /api/auth/register` - تسجيل حساب جديد
- `POST /api/auth/login` - تسجيل الدخول
- `POST /api/auth/social-login` - دخول عبر وسائل التواصل
- `GET /api/auth/me` - جلب بيانات المستخدم الحالي
- `POST /api/auth/logout` - تسجيل الخروج

### الدردشة والاستشارات
- `POST /api/chat/session` - إنشاء جلسة دردشة جديدة
- `GET /api/chat` - جلب جميع المحادثات
- `POST /api/chat/:id/message` - إرسال رسالة
- `DELETE /api/chat/:id` - حذف محادثة

### الأدوية
- `POST /api/medicine/search` - البحث عن دواء بالاسم
- `POST /api/medicine/recognize` - التعرف على دواء من صورة
- `GET /api/medicine/:id` - جلب تفاصيل دواء
- `GET /api/medicine` - قائمة الأدوية الشائعة

### التحاليل الطبية
- `POST /api/lab/upload` - رفع نتيجة تحليل
- `POST /api/lab/analyze` - تحليل نتيجة
- `GET /api/lab/tests` - سجل التحاليل
- `GET /api/lab/common` - التحاليل الشائعة

### الأشعة الطبية
- `POST /api/radiology/upload` - رفع صورة أشعة
- `POST /api/radiology/analyze` - تحليل أشعة
- `GET /api/radiology/exams` - سجل الأشعة
- `POST /api/radiology/export` - تصدير تقرير DICOM

### التقارير الطبية
- `POST /api/reports/create` - إنشاء تقرير جديد
- `GET /api/reports` - جلب جميع التقارير
- `GET /api/reports/:id` - جلب تقرير محدد
- `POST /api/reports/:id/export` - تصدير التقرير (PDF/DOCX/DICOM/FHIR)
- `DELETE /api/reports/:id` - حذف تقرير

### سجل العمليات
- `GET /api/activity` - جلب سجل العمليات
- `GET /api/activity/stats` - إحصائيات الأنشطة
- `POST /api/activity/export` - تصدير السجلات

### الثيمات
- `GET /api/themes` - جلب الثيمات المتاحة
- `POST /api/themes/custom` - حفظ ثيم مخصص
- `PUT /api/themes/:id` - تحديث ثيم

### الملفات
- `POST /api/files/upload` - رفع ملف طبي
- `GET /api/files` - جلب الملفات
- `DELETE /api/files/:id` - حذف ملف

### الاشتراكات
- `GET /api/subscriptions/plans` - جلب خطط الاشتراك
- `POST /api/subscriptions/subscribe` - الاشتراك في خطة
- `GET /api/subscriptions/current` - الاشتراك الحالي
- `POST /api/subscriptions/cancel` - إلغاء الاشتراك

### الإدارة
- `GET /api/admin/stats` - إحصائيات المنصة
- `GET /api/admin/users` - إدارة المستخدمين
- `GET /api/admin/subscriptions` - إدارة الاشتراكات
- `GET /api/admin/activity` - مراقبة الأنشطة
