# 🩺 منصة طبيب العجائب | Tabib Al-Ajayeb

منصة ذكاء اصطناعي طبية متكاملة مع وكلاء متخصصين لتحليل الأشعة والتحاليل وتقديم استشارات طبية احترافية.

## ✨ المميزات

- **8 وكلاء ذكاء اصطناعي متخصصين**:
  - الدكتور العام (الطب العام)
  - دكتور الأشعة (تحليل الأشعة)
  - دكتور التحاليل (التقارير المعملية)
  - دكتور القلب (أمراض القلب)
  - دكتور المخ والأعصاب
  - دكتور الجلد (الأمراض الجلدية)
  - دكتور الأطفال
  - الاستشاري العام (للحالات المعقدة)

- **دعم رفع الملفات**: صور، PDF، Word، نصوص
- **دعم الصوت**: التحدث مباشرة مع الذكاء الاصطناعي
- **تسجيل الدخول الاجتماعي**: Google, Facebook, GitHub
- **خطط اشتراك متعددة**: مجاني، ذهبي، بلاتيني
- **طرق دفع مصرية**: فودافون كاش، اتصالات كاش، اورنج كاش، وي كاش، فوري، ميزة
- **لوحة تحكم للمدير**: إدارة المستخدمين والوكلاء
- **دعم +30 مزود ذكاء اصطناعي**: OpenAI, Google AI, Anthropic, Cohere, Replicate, HuggingFace

## 🚀 التقنيات المستخدمة

- **Frontend**: React 18, Vite, Zustand
- **Backend**: Node.js, Express, Firebase
- **Database**: Firebase Firestore
- **Storage**: Firebase Storage
- **AI Providers**: OpenAI, Google AI, Anthropic, Cohere, Replicate, HuggingFace

## 📦 التثبيت

```bash
# تثبيت التبعيات
npm install

# نسخ ملف البيئة
cp .env.example .env

# تعديل ملف .env بمفاتيح API الخاصة بك

# تشغيل التطوير
npm run dev

# تشغيل الخادم الخلفي
npm run server
```
