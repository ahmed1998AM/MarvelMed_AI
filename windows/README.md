# طبيب العجائب - تطبيق سطح المكتب

## متطلبات التشغيل
- Node.js 18+ 
- npm أو yarn

## التثبيت والتشغيل

### للتطوير:
```bash
npm install
npm run dev
```

### للإنتاج:
```bash
# بناء التطبيق
npm run build

# حزمة التطبيق للويندوز
npm run build:win

# حزمة التطبيق للماك
npm run build:mac

# حزمة التطبيق للينكس
npm run build:linux

# حزمة لجميع المنصات
npm run build:all
```

## المميزات
- تطبيق سطح مكتب كامل
- دعم رفع الملفات المحلية
- تكامل مع نظام الملفات
- واجهة عربية كاملة
- إشعارات سطح المكتب
